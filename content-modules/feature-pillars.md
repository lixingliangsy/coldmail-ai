# ColdMail AI — Feature pillars

## Core engine
- Research-backed personalized cold emails for LinkedIn, X, or email
- Multiple tones (founder / formal / casual) with subject-line variants
- Reply and follow-up generators to keep the thread consistent

## Workflow & output
- Prospect-context personalization instead of generic blast copy
- Channel-aware phrasing while keeping the core pitch
- Copy-ready drafts for founders and freelancers doing outbound

## Trust & control
- CAN-SPAM hygiene reminders via rule checks (unsubscribe, no deceptive subject)
- Decision-support — review before send; no guaranteed reply rates
- Demo mode without a live API key
